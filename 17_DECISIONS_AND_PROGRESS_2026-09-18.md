## Подтверждено

| Решение | Смысл и граница |
|---|---|
| Относительная оригинальность | Главное требование, а не необязательное украшение обычного survivor |
| Пересмотр с нуля | Существующие Chain, каталог, прогрессия и архитектура не являются неприкосновенными |
| Личный соперник | Предпочтение конкретному носителю истории отказов, а не общему невидимому усилению мира |
| Ограниченное противодействие | Враг использует полученное, не становится универсальным контрбилдом |
| Адаптированная общая механика | Не буквальное копирование оружия против толпы на единственного героя; общий принцип должен узнаваться |
| Четыре активных феномена | Не четыре предмета во всём каталоге; резерв тоже нужно уменьшить |
| Разнообразный стартовый каталог | Ориентир 14+ видов и более широкий набор преобразований, если слой сохранится |
| Поздние находки | Не возвращать личные вложения в оружие/слоты, делающие замену невыгодной по определению |
| Сильные выигрыши | Положительные мутации и редкие чрезмерно сильные сочетания допустимы |
| ИИ и движение | Значительно пересмотреть элит, отряды, обычных врагов; не ограничиваться ростом HP |
| Не жёсткие классы элит | Отличительные черты допустимы, фиксированная профессия не обязательна |
| Дэш | Общее направление поддержано, конкретные параметры не утверждены |
| Потенциал развития | Накопительный рост плюс возможные вложения в будущее; не только боевые эффекты |
| Четвёртое действие | Редкая дополнительная возможность, не замена одной из трёх обычных наград |
| Оцениваемость | Формулы и баланс входят в следующий срез; мгновенная гибель всех элит не даёт оценить идею |

## Отложено или не принято

- Неатакующие феномены отложены. Агро-двойник интересен, но не выбран для реализации.
- Отдельный развиваемый слой базовой автоатаки не включён.
- Каталоги 14/20 из документа 15 не приняты; пользователь указал на избыточную привязку к старому оружию.
- Переправа, разведка, извлечение и инфраструктура ради них не включены.
- Межзабеговая метапрогрессия находится в бэклоге.
- Все разновидности отсрочки нельзя выдавать за разные решения задачи потенциала. Опыт, удача и пока не сформированные действия с элитами нужно рассматривать шире.
- «Сочетание» в ответе пользователя не утвердило поставки, исследования, проекты или экономические валюты.
- Частота редкого действия и его выплата через удачу пока являются предложением, не формулой.
- Условные проценты казино-исходов не являются согласованным распределением.

## Нерешённые решения

| ID | Решение | Почему влияет на срез |
|---|---|---|
| O1 | Ячейки, связи, Chain, ритм и размещение преобразований | Меняет API боя, UI и смысл каталога |
| O2 | Новый каталог и совместимость | Нельзя реализовывать отклонённую старую подборку по умолчанию |
| O3 | Доля соперника, третья карта, дубликаты, перебросы, пропуски | Определяет экономику драфта и возможность стратегического запрета |
| O4 | Резерв героя и активный/запасной репертуар элиты | Ограничивает универсальность и сложность |
| O5 | Получатель до появления/после смерти, подготовка, число соперников | Связывает частые встречи и узнаваемую историю развития |
| O6 | Собственный рост элиты и момент переоснащения | Не допустить скрытых контрспособностей и изменения объявленной атаки |
| O7 | Общие выборы против личной прогрессии | Дополнительный XP не должен молча менять правила роста врага; ответа ещё нет |
| O8 | Опыт, удача и другие свойства потенциала | Нужны настоящие разные направления, не обязательный ранний экономический выбор |
| O9 | Редкое четвёртое действие | Цена, основная тройка, срок, случайность, выплата, окончание забега, доля элиты |
| O10 | Возможные действия с элитами ради будущего | Пока только область поиска, не готовая идея |
| O11 | Трофеи и отмена эффектов после смерти | Нельзя молча выдать весь вражеский набор или бесконечный фарм |
| O12 | Управление, дэш, защита и восстановление | Определяет честность ответов и цену ошибок |
| O13 | Геометрия, навигация, бюджет отрядных действий | ИИ не работает без реальных маршрутов и ограничений давления |
| O14 | Формулы, объём забега и проверка | Должны позволить оценить концепцию, а не её числовой перекос |

## Кодовая опора

Для фактов о текущем runtime были прочитаны `prototype/current/src/content/definitions.ts`, `src/core/types.ts` и отдельные области `src/core/simulation.ts`. Основные точки: `spawnDirector`, `eliteDirector`, `updateEnemyAI`, `updateEliteAI`, `generateLevelOffers`, `generateDiscovery`, `generateEliteCache`, `chooseReward`, `swapSkillLocations`.

Сейчас выбор применяет только выбранную награду; наследования отказов соперником нет. Текущая масса пополняется преимущественно директором отдельных появлений, а не новой системой отрядных операций. При этом в коде уже есть разные типы поведения; неверно утверждать, что все враги отличаются только спрайтом.

CodeGraph был вызван, но сообщил об отсутствии инициализированного индекса. Индекс не создавался. Graphify-графа не было. Навыки ccc/Graphify были загружены, семантический индекс в этой работе не строился. Затем применялись точечные чтения известных из снимка файлов. При новом кодовом исследовании сначала проверить доступную кодовую разведку, не выдавать старые номера строк за текущие.

`simulation.v09c.bak` и старые каталоги не подменяют активный runtime. `SHA256SUMS.txt`, `MANIFEST.md` и `VALIDATION_CURRENT_BUILD_2026-09-17.txt` сохранены как исторические артефакты исходного пакета, не как проверка новых документов или будущей концепции.
