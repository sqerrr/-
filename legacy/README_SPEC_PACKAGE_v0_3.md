# Предпродакшен-спецификация roguelike / survivors-like v0.1

Этот каталог — рабочий пакет для начала разработки предлагаемого автобаттлер-рогалика с цепочкой навыков.

## Читать в таком порядке

1. **`GAME_SPEC.md`** — базовая продуктовая, геймплейная и UX-спецификация.
2. **`BALANCE_SPEC.md`** — формулы, правила стакинга, масштабирование мира, RNG и количественные ориентиры.
3. **`IMPLEMENTATION_SPEC.md`** — исполняемая архитектура, порядок систем, контракты данных и обязательные тесты.
4. **`CONTENT_CATALOG.md`** — конкретные навыки, 120 мутаций, катализаторы, Законы, элитки, адаптации, монстры и POI.
5. **`META_PROGRESSION_SPEC.md`** — прогрессия между ранами, темп открытия контента, Research Focus и лестница сложности.
6. **`AI_MCP_SPEC.md`** — опциональная система командиров-элиток с AI/MCP.
7. **`RESEARCH_BENCHMARKS.md`** — ориентиры и выводы из успешных игр.

Сгенерированные поверхности проверки:

- `INTERACTIONS.generated.md` — системные связи производитель/потребитель состояний.
- `CHAIN_SPACE.generated.md` — аудит пространства упорядоченных цепочек из шести слотов.
- `CONTENT_MATRIX.generated.md` — матрица покрытия контента и проверка против «контента ради контента».
- `RUN_PROBES.generated.md` — заранее составленные жизнеспособные и «хорошие только на бумаге» билды.
- `CALIBRATION.latest.txt` — последний консольный снимок Monte-Carlo-калибровки.

Машиночитаемый источник:

- `data/catalog_v0_1.json`

## Инструменты

Запускать из этого каталога:

```bash
python tools/render_catalog_md.py
python tools/content_linter.py
python tools/combo_audit.py
python tools/chain_space_audit.py --samples 10000 --seed 1337
python tools/content_matrix.py
python tools/balance_calibrator.py --runs 10000 --seed 1337
python tools/build_probe.py --runs 2000 --seed 7000
```

### Философия инструментов

Инструменты — **сигнализация, а не автоматический геймдизайнер**. Они должны находить дубли, обязательные хабы, мёртвые области графа, случайные proc-loop'ы и схлопывание вариативности ранов. Они не должны автоматически нормализовать каждый выброс: редкие авторские «сломанные» комбинации — часть целевого опыта.

## Текущее количество контента

- 24 навыка;
- 120 мутаций навыков;
- 28 катализаторов;
- 24 легендарных Закона;
- 8 шасси элиток;
- 12 общих аффиксов элиток;
- 16 семейств адаптаций, каждое с выражениями Rare/Epic/Legendary;
- 24 обычных монстра в трёх концептах биомов;
- 10 POI.

Это **кандидаты дизайна**, а не обещание, что каждый элемент войдёт в релиз без изменений.

## Текущие автоматические выводы

- линтер контента: 0 ошибок / 0 предупреждений по текущему эвристическому контракту;
- 63 направленные системные связи Skill→Skill через состояния до учёта катализаторов;
- для случайных наборов из шести навыков медианная лучшая перестановка имеет 4/5 значимых соседств;
- вероятность набора из шести навыков вообще без синергии сейчас около 0,1%;
- ранний аудит обнаружил чрезмерную центральность состояния `displaced` и доминирование Mass Driver как универсального хаба; каталог был исправлен разделением `compressed` и обычного перемещения;
- упрощённая балансовая модель пока делает связные low-roll раны несколько слишком прощающими, поэтому в первых плейтестах нужно в первую очередь проверять реальное давление встреч и элиток, а не просто поднимать HP врагам.

## Язык технических идентификаторов

Основной текст спецификаций и текущие снимки аудитов локализованы на русский. Code ID, имена структур, state-теги, названия рабочих Skills и часть терминов в консольном выводе оставлены английскими намеренно — они совпадают с JSON и будущим кодом. См. `TERMINOLOGY.md`.

Скрипты в `tools/` пока являются code-facing инструментами и при повторной генерации отдельных `.generated.md` могут вывести англоязычные служебные заголовки. Это не меняет русские продуктовые спецификации; локализацию генераторов следует сделать отдельным небольшим engineering-task, если отчёты станут частью ежедневного дизайнерского workflow.
