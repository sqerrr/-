# Playtest v0.10 — CORE REBUILD SANDBOX

This test is about **decisions, replacement, visible synergies and Elite identity**. Do not begin by recording DPS spreadsheets. A difficult/easy run is secondary until the new core proves it is more interesting.

## 1. Does horizontal expansion finally feel good?

Start a Clean Run and pay attention when the second, third and fourth Phenomenon arrive.

Check:

- does a new Phenomenon feel like added capability rather than a hidden nerf to the old one;
- can you still recognize the natural cadence of the first Phenomenon;
- does the screen become richer without immediately becoming unreadable;
- do you ever reject a new Phenomenon because of actual build fit rather than fear that it will steal XP from the carry.

## 2. Late Phenomenon pivot

At least once, deliberately keep an alternative Phenomenon in the Archive for several minutes and then swap it active.

Ask:

- does it immediately contribute at a plausible current-run power level;
- if you still prefer the old Phenomenon, is the reason synergy / role / global axes rather than “the new one is level 1”;
- does the swap create an understandable new strength and weakness;
- after one strong late discovery, do you ever seriously consider rebuilding two or more Chain positions.

A core failure is: **“Archive still contains things I know I will never use again.”**

## 3. Core Axes

After several XP choices, describe your run without naming a weapon.

Examples of the desired type of statement:

- “this run became very fast-cycle”;
- “this run is heavily count-based”;
- “this run depends on Catalyst conductivity.”

Failure cases:

- one axis is obviously best for nearly every roster;
- the choice feels like generic `+damage` under another name;
- a late Phenomenon cannot plausibly benefit from anything you already built;
- axes are too weak to create build identity.

Record which axes you almost never want.

## 4. Phenomenon identity

For every active Phenomenon answer two questions without opening the planner:

1. **When am I glad I have this instead of another Phenomenon?**
2. **What situation exposes its weakness?**

If the answer is just “this one is AoE / this one is single-target”, the Phenomenon is not differentiated enough.

Special attention:

- Cleaver should justify dangerous close positioning with payoff;
- piercing Beam should become better when enemies line up / become dense, not merely behave as another projectile;
- Mortar should dominate packs but feel awkward under fast close pressure;
- Frost should visibly change crowd flow even when its direct damage is not impressive.

## 5. Catalyst behavior, not Catalyst DPS

For each found Catalyst, first try to predict its effect from the text, then watch it in combat.

Ask:

- what exactly did this edge change: timing, target, position, count, memory, topology, defence, state/fusion?
- can I see the causal relation without staring at damage numbers;
- if I move the Catalyst to a different edge, does the machine *behave* differently;
- do I ever want a Catalyst because of an unusual rule even when it is not obviously the highest DPS option;
- how many active Catalysts can still be summarized as “A causes B to attack again”. More than half is a design failure.

Specifically test:

- **Anchor** with a Phenomenon whose targeting/geometry makes centroid routing meaningful;
- **Capacitor** with a high-target-count left side and a right side that visibly uses extra instances;
- **Reservoir** long enough to see accumulation/release;
- **Backflow / Overflow** for visible direction/topology change;
- **Aegis Relay** to verify that a Catalyst can create survivability rather than damage.

## 6. Mutation should feel like evolution

On receiving a Mutation Core:

- does choosing a mutation feel like a major positive event;
- is the original Phenomenon still recognizable after evolution;
- did the mutation add a new capability / new synergy rather than simply trading away one useful axis;
- if you later swap that Phenomenon out, does reclaiming the Core make experimentation feel acceptable rather than punitive.

Record any mutation whose first emotional response is “why did this make my weapon worse?”

## 7. Elite recognition — do not read the name first

For the first encounters with each anomaly, deliberately ignore the banner for a few seconds and identify it by behavior.

### Хищник

- does it actually intercept/predict rather than merely walk faster;
- are dash intentions readable;
- does changing movement alter the encounter.

### Завеса

- is the veil obvious spatially;
- do you notice distant auto-targeting behaving differently;
- can directional/manual geometry still solve the problem;
- does it feel like fog/targeting disruption rather than “my weapon randomly stopped.”

### Репликатор

- can you connect frequent hit events to copy creation;
- is killing copies a visible alternate route to hurting the parent;
- do high-frequency and low-frequency builds experience it differently without one receiving a simple immunity wall.

### Призма

- can you tell when one source has been imprinted;
- does changing Phenomenon source visibly break/expose it;
- does a diverse Chain solve it naturally;
- is the rule readable without memorizing slot numbers.

### Нуль-ткач

- are captured Catalyst-derived charges visible;
- can direct Phenomenon hits deliberately discharge them;
- does Catalyst-heavy play create an interesting problem rather than just lower damage.

### Метаморф

- does the form transition happen even when damage is very high;
- can you tell that different recent damage signatures produce materially different forms;
- is the new form a behavior change, not only a resistance/stat change.

If an Elite can still be described as **“a normal mob with more HP and a colored aura,”** log it as a core failure even if the numbers are balanced.

## 8. Jackpot stress test

When the run becomes very strong, do **not** ask whether the director successfully normalizes you back to average.

Instead ask:

- are you allowed to erase some ordinary Elites quickly;
- do structural anomalies still occasionally make you notice what is happening;
- do the strongest encounters create a different problem instead of simply multiplying HP;
- does feeling overpowered remain fun rather than being immediately punished by hard counters.

## 9. Density and ordinary mobs

The current build deliberately raises density.

Check:

- do Phenomenon strengths/weaknesses become clearer with larger crowds;
- are normals still too behaviorally similar despite the higher count;
- does the game create pressure through mass/roles rather than projectile soup;
- are Elite rules still readable through the crowd;
- does movement create useful positioning rather than only perpetual circle-kiting.

The current density numbers are provisional. If survival is simply too hard, record *why* damage reaches you before proposing a blanket population reduction.

## 10. Map / POIs

POIs no longer exist to summon yet another guardian Elite.

Ask:

- does a POI reward give a reason to travel when free Elites are already frequent;
- which build-control function would make the node genuinely exciting: reforge Catalyst trigger/operator, steer Discovery, reroute Mutation, preview choices, transmute, recovery, something else;
- does the bounded map still need stronger terrain/route structure beyond icons.

## 11. End-of-run notes

After each run write these seven sentences:

1. “My machine became ___ because I chose ___.”
2. “The late discovery I most wanted to pivot around was ___.”
3. “The Catalyst that changed behavior most visibly was ___.”
4. “The Phenomenon with the clearest strength/weakness was ___.”
5. “The Elite I recognized fastest was ___ because ___.”
6. “The Elite that still felt like an ordinary mob was ___.”
7. “The biggest reason to explore / not explore was ___.”

Those answers are more valuable for the next pass than a single final DPS number.
