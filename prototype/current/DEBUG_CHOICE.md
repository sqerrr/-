# Choice diagnostics v0.8

Система диагностики выбора сохранена после старого modal-багa.

Нажмите `F8`, чтобы открыть панель. Она пишет DOM click/pointer events, `choiceSerial`, состояние pending reward/mutation, состояние модального окна до/после выбора и runtime errors/rejections. Кнопка «Скопировать лог» копирует последние записи вместе с версией и user agent.

В обычном playtest панель скрыта и на gameplay не влияет.
